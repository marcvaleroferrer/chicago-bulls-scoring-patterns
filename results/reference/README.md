# Historical reference results

`selected_results.csv` is a manual transcription of displayed thesis/HTML values,
not the output of a new fit. Precision is limited to the displayed digits.
Different sources are separate rows, including disagreements in objectives.
The `negative_log_likelihood` label makes the original objective sign explicit.
Source hashes and the archive-to-repository mapping are in `docs/provenance.md`.

`example_intensity_game59.png` is an unchanged copy of the original definitive
illustration, using fixed parameters rather than an estimated model. Its title
and curve agree with the thesis Figure 5.1; exact regeneration is not asserted.

Original HTML archives remain outside the cleaned repository. Their names in
the CSV are provenance identifiers, not broken links to files in this folder.
